# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| Latest 2.0 pre-release | ✓ |
| 1.4.x | Security fixes only |
| Anything else | ✗ |

## Reporting a vulnerability

Report vulnerabilities privately by email to **networking-automation@hpe.com**.
Do not open public GitHub issues for security problems.
